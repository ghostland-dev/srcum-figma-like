# Figma-like Editor

Lightweight Figma-style design editor (Scrum team project).

## Features

- React + TypeScript + Vite
- Tailwind UI

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS

## Getting Started

```bash
git clone https://github.com/ghostland-dev/scrum-figma-like.git
cd scrum-figma-like
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
